# 无锡职院公选课选课脚本

选课窗口：**10 月 20 日 13:30 — 10 月 23 日 13:30**，每人最多 2 门。

给你两套方案。**先用方案 A**，它在你已登录的浏览器里直接点“选课”，不碰登录、验证码和门户 SSO；方案 B 更“脚本化”，但需要先确认教务系统选课页的接口结构。

## 方案 A：Tampermonkey 小窗版（推荐）

1. 给 Chrome / Edge 装 **Tampermonkey** 扩展。
2. 点扩展图标 → “添加新脚本”，把编辑器里的内容全删掉，粘贴 [抢课助手.user.js](抢课助手.user.js) 全文，按 `Ctrl+S` 保存。
3. 登录 <https://rhmh.wxut.edu.cn/>，进“智慧教务” → 学生选课，打开选课轮次页（地址形如 `/jsxsd/xsxk/xklc_list?...`）。
4. 页面右上角出现“公选课助手”小窗：
   - 每行填一门：课程名称 + 教师（教师可留空，但同名课多时建议填）；
   - 每门右侧选类别：**文化 / 艺术 / 不限**。脚本会先保证两类各有一门——先抢你列表里优先级最高的一门，再自动补另一类，两类都覆盖后才按优先级加课；页面有“文化素质课 / 公共艺术课”分类标签时会自动切过去找。已经选过的课（页面上有“退课”按钮）也会计入，不会白占名额；
   - **课名留空、只选类别**就是“该类别任意一门”的保底目标：脚本从页面里挑一门同类可选课，某门提示人数已满会自动换同类下一门，不用写具体课程名；
   - 第二行可以选**教室**（支持部分匹配，如填“崇德205”），下拉候选会自动收集当前页面出现过的教室；填了教室就只抢该教室的课；
   - 勾选**终极模式**后：自动过滤余量为 0/已满的课程，按你设置的“查询间隔”反复扫描（0.3–10 秒，默认 0.8 秒，运行中也能改）；页面“查询”按钮的点击频率自动取间隔的 3 倍（最少 2 秒），一旦有人退课放出位置就立刻抢，不设尝试次数上限，直到抢到或手动停止。
   - 终极模式下，课名、教师、类别、教室**全部留空**就是“任意一门有空位的课”：哪门先出位置抢哪门，抢到一门即停；只想限定教室时，只填教室即可。
   - 点“检测”，日志会告诉你每门目标有没有在当前页面匹配到，并显示匹配到的行内容；
   - 想卡点就在“开始”里填 `13:29:58`，再点“开始”，到点自动动手；不填则立即开始；
   - 在**选课轮次页**点“开始”时，脚本会自动点“进入选课”，进入课程列表后自动继续，不用再操作一次；
   - 如果进入的课程页结构不认识，点“结构”会复制一段页面 HTML，发我就能按真实结构改。

小窗可以拖着走，点 `—` 或按 `Alt+X` 折叠；位置和填写内容存在浏览器本地（本站 localStorage），刷新页面不会丢。运行中它会每 1.2 秒扫一遍课程表，按从上到下的优先级点击“选课”，自动确认弹窗，选满设定门数自动停；只点“选课”，不会退课或改其他数据。

> 如果小窗没出现，多半是选课页不在 `zhjw.wxut.edu.cn/jsxsd/` 路径下（比如新版“智慧教务”换了域名）。把浏览器地址栏的地址发我，我加一条 `@match`。

## 方案 B：Python 脚本

```powershell
cd <本文件所在目录>
pip install requests
python xk.py login          # 输入学号和教务系统密码，密码不回显、不落盘
python xk.py list           # 先确认能列出课程，并生成 .xk_runtime/dump/courses.csv
```

然后在 `config.json` 里按优先级填目标，运行：

```powershell
python xk.py grab           # 正式抢课
python xk.py grab --dry-run # 只演练，不提交
```

`config.json` 示例：

```json
{
  "max_courses": 2,
  "interval_seconds": 3,
  "jitter_seconds": 1.0,
  "refresh_seconds": 15,
  "deadline": "2026-10-23 13:30",
  "targets": [
    {"name": "AIGC应用", "teacher": "史荧中"},
    {"name": "书法实践", "teacher": "糜杨凡", "time": "星期二 09101112节"}
  ]
}
```

### 登录不上怎么办

如果教务系统要求验证码，或者只能用统一门户单点登录，走 Cookie 复用：

1. 浏览器正常登录并进入选课页；
2. `F12` → Network，点任意一个 `zhjw.wxut.edu.cn` 请求，复制请求头里的 `Cookie`；
3. 运行 `python xk.py list --cookie "bzb_jsxsd=....; SERVERID=..."`。

### 排错

```powershell
python xk.py dump
```

会把选课中心和相关页面、脚本存到 `.xk_runtime/dump/`。如果 `list` 显示“没有解析到课程”，把这个目录里的内容发我，我按真实页面结构改解析和提交参数。

## 说明与边界

- 默认 3 秒一次选课请求、每门课最多 80 次，属于单账号低频操作；不建议把间隔调到 1 秒以下。
- 脚本只做“登录 → 读课程列表 → 提交选课”这几步，不绕过验证码、不伪造身份、不修改成绩等其他数据。
- 自动化选课可能与学校管理规定冲突，风险自行评估；建议同时保留手动操作。
- 课程清单（90 门，来自通知附件）见 [2026-2027-1公选课清单.csv](2026-2027-1公选课清单.csv)。

## 安全与隐私

- 脚本本身不包含学号、密码或 Cookie；Python 版密码是交互输入，不写入文件。
- 运行 `python xk.py login` 后会生成 `.xk_runtime/cookies.json`，里面是**可用的登录会话**，等同于临时密码，已被 `.gitignore` 排除，也不要发给别人或提交到 GitHub。
- 浏览器版的选课目标只存在本机 localStorage，不在这些文件里。
- 上传前可自查：仓库里不应出现 `.xk_runtime/`、`cookies.json`、`*.log`；`git status` 里看到它们就说明忽略了没生效。
